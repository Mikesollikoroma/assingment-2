# Assingment 2
## Description 
This project is based on and inspired by the Liverpool F.C. website and the current team for 2024. I have followed the criteria, and all player cards contain an image of the player and four pieces of information: position, number, nationality, and age. There are 15 cards on display. I have also included a league table for 2024–2025, accessible via the navbar.
